# 電子取引データの保存に関する事務処理規程（ひな形）

> 下書き。国税庁「電子取引データの訂正及び削除の防止に関する事務処理規程」のひな形を基に、ムーアの運用に合わせた。税理士の確認前は正式な規程として使わない。

ムーア株式会社（以下「当社」）は、電子取引（電子署名サイトで締結する契約書等）のデータを、電子帳簿保存法に従って次のとおり保存する。

## 第1条（対象）
当社が sign.mooores.com で授受する、NDA・業務委託基本契約・個別契約・診断作業の許可書・運用の同意書の署名済み PDF と、その監査ログ。

## 第2条（管理責任者）
事務処理の責任者は代表取締役とする。（氏名・日付は正式版で記入）

## 第3条（保存の方法）
1. 署名済み PDF と監査ログは、署名完了後すみやかに当社の指定する Google ドライブのフォルダに保存する。
2. ファイル名は `取引年月日_取引先_金額.pdf`（監査ログは末尾に `_log`）とする。取引年月日は署名完了日、金額は契約書上の金額（無い場合は 0）。
3. 保存期間は取引年月日の属する事業年度の末日から7年間とする。
4. 署名サイトのデータは Supabase に保存し、週1回、暗号化して別の保管先（Cloudflare R2）に複製する。

## 第4条（検索）
ドライブ上のファイル名の検索により、取引年月日・取引先・金額で検索できるようにする。日付と金額は範囲でも探せるよう、規則どおりの名前を守る。

## 第5条（訂正・削除の防止）
1. 保存した署名済み PDF は、訂正も削除もしない。
2. 誤りがあったときは、新しい契約書または覚書を別に結び、元のデータは残す。
3. 削除権限は管理責任者のみが持つ。保存期間内に削除する場合は、理由と日付を記録する。
4. 署名済み PDF の暗号署名とタイムスタンプ（付す場合）により、改ざんの有無を確認できる。

## 第6条（見読性の確保）
パソコンとディスプレイ、プリンターを備え、保存データを速やかに表示・印刷できるようにする。

## 第7条（システムの説明書類）
署名サイトの運用手順書（docs/ops.md）を、システム概要の書類として備え付ける。
