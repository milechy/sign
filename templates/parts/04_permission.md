## 4. 診断作業の許可書

［甲：会社名］（以下「甲」）は、ムーア株式会社（以下「乙」）に対し、個別契約書（AIセキュリティ診断）に基づく診断作業を次の範囲で行うことを許可し、不正アクセス行為の禁止等に関する法律第2条第4項に定める承諾を与えます。甲は、下の「対象」の各システムについて、甲がアクセス管理者であること、またはアクセス管理者から診断に必要な承諾を得ていること（第三者が管理するサービスは、その利用規約で認められた範囲であること）を表明します。この書面にない作業は許可していません。

### 許可する範囲

| 項目 | 内容 |
| --- | --- |
| 対象 | ［例：Microsoft 365 テナント（contoso.onmicrosoft.com）、Google Workspace、WordPress（https://example.co.jp）、自社SaaS（ステージング環境のURL）］ |
| 対象外 | ［例：本番の決済機能、取引先が管理するシステム］ |
| 期間 | ［開始日時］〜［終了日時］ |
| 作業時間帯 | ［例：平日9時〜18時］ |
| 方法 | 管理画面・設定の閲覧、公開範囲・共有設定・権限の棚卸し、ログの確認、公開情報の確認、［WordPress：プラグインとバージョンの確認］ |
| 乙が使うアカウント | ［アカウント名・権限（原則として閲覧のみ）］ |
| 甲の連絡窓口 | ［氏名・電話・メール］（作業中に連絡がつく方） |
| 乙の作業者 | ［氏名］ |

### 行わないこと

1. 乙の作業は、甲が発行する乙専用のアカウントでの閲覧、設定内容の確認、公開情報の確認に限ります。甲の社員本人のアカウントは借りません。
2. アクセス制御を回避・無効にする操作、脆弱性スキャン、侵入テスト（ペネトレーションテスト）、負荷試験は行いません。
3. 設定の変更、データの削除・移動は、この診断では行いません。強化の段階で、甲の承認を得てから行います。
4. 自社SaaS・アプリはステージング環境で確認し、本番環境には触れません。

### 約束ごと

1. アクセス管理者が第三者（Microsoft、Google などのクラウド事業者）のときは、甲は、その事業者の規約に反しない範囲であることを確認します。
2. 甲が上の権限を持っていなかったために、乙が第三者から請求や捜査などを受けたときは、甲はそれによる乙の損害（弁護士費用を含む）を補償します。ただし、乙が権限がないことを知っていたときは除きます。この補償は刑事責任をなくすものではないため、乙は権限に疑いがあるときは作業を止めることができます。
3. 作業中に重大な問題（外部に公開された個人情報、不正アクセスの痕跡など）を見つけたときは、作業を止め、直ちに甲の連絡窓口に知らせます。
4. 診断で得た情報は秘密保持契約書に従って扱い、報告書の作成が済んだら乙が持つ控えを［30］日以内に削除します。
5. 診断は、確認した時点・範囲での状態を報告するもので、安全であることを保証するものではありません。
6. 第三者に提出する正式な診断報告や侵入テストが必要なときは、専門の診断会社をおすすめします。
